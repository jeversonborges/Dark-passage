# Dark Passage

MMORPG clássico, escuro e retrô, no espírito de Dark Eden, MU Online e Ultima Online. Cliente isométrico em Godot 4.

- `game/`: projeto Godot (o `game/README.md` tem os comandos de build, teste e publicação)
- `assets/`: personagens, monstros, ambiente, interface, efeitos, ícones e áudio
- `design/`: classes, combate, missões, mapas, skills e itens
- `tools/`: pipelines de sprites (Blender), efeitos e ícones

Os builds para Windows não ficam no repositório.
