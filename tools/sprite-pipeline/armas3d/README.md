# Armas 3D fiéis às artes

Um modelo por arma, feito por código no Blender (bpy 4.2, `/root/bpy42`), seguindo a sheet pintada do Jefin.

- `machado_gladiador.py`: Machado do Gladiador Demoníaco (arma PvP do Mutante).
  `/root/bpy42/bin/python machado_gladiador.py -- <saida>` gera o `.glb` e 8 renders (`render_0..7.png`).
  Variáveis: `AMOSTRAS` (padrão 48), `RES` (padrão 384).

Pendente: print em uso na mão do Mutante (precisa do holdout do corpo, como em `entregas/armas_camada`).
